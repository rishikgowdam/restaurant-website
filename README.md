# Restaurant Website — Module 5 Practice

This is a self-contained practice website inspired by the Coursera Module 5 assignment. It includes a restaurant homepage, Menu, Specials, and Map sections. Clicking **Specials** selects a random category (Lunch, Dinner, Sushi, or Appetizers).

## Run it
1. Unzip the downloaded folder.
2. Open the `restaurant-website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use a local development server such as the VS Code Live Server extension.

This demo is self-contained and does not need a backend. It is an adapted practice project, not the official Coursera starter files. The address, menu items, and prices are sample content.

## Main files
- `index.html` — page structure
- `css/styles.css` — layout and responsive styling
- `js/script.js` — menu rendering and random Specials behavior

## GitHub Pages
Upload the contents of this folder to a GitHub repository, with `index.html` at the repository root. Then enable GitHub Pages from **Settings → Pages** and deploy from the `main` branch and `/ (root)` folder.
